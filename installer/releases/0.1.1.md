# Strahlender Installer 0.1.1

Turns your own *Pokémon Brilliant Diamond / Shining Pearl* files into a native app on macOS, Linux and Windows. Pick your system, start the installer, drop in your files, follow the build.

> [!TIP]
> 🇩🇪 **Strahlender** = *brilliant*: the same word as in *Brilliant Diamond*.

> [!NOTE]
> **iPhone and iPad:** iOS and iPadOS builds are part of the macOS installer. They are built on a Mac with Xcode and your device connected.

## Download

| System | File | Start |
| --- | --- | --- |
| **macOS** · Apple Silicon and Intel | `Strahlender-Installer-macOS-universal.zip` | Unzip, open *Strahlender Installer* |
| **Linux** · x86_64 | `Strahlender-Installer-x86_64.AppImage` | Make it executable, run it |
| **Linux** · ARM64 | `Strahlender-Installer-aarch64.AppImage` | Make it executable, run it |
| **Windows** · x86_64 | `Strahlender-Installer-x86_64.exe` | Run it, nothing to unpack |

> [!IMPORTANT]
> **macOS:** the installer is not notarized by Apple (notarization is Apple's automatic malware scan for apps outside the App Store), so macOS blocks the first start with *"Strahlender Installer" Not Opened: Apple could not verify "Strahlender Installer" is free of malware that may harm your Mac or compromise your privacy.* That is expected. Allow it once:
> 1. Try to open the app and click *Done* (not *Move to Bin*).
> 2. Open *System Settings → Privacy & Security*, scroll down and click **Open Anyway**.
> 3. Confirm with your password and click *Open*. From then on it starts like any other app.
>
> Since macOS 15 the old right-click → *Open* shortcut no longer works, so the steps above are the way. If macOS says the app is *damaged*, see the technical details below.
>
> **Windows:** the installer is not code-signed. SmartScreen may show *Unknown publisher*; choose *More info → Run anyway*.

## What you need

- Your own `prod.keys` and the base game.
- Optional: the game update. **Update 1.3.0 is preferred.**
- Optional: your Switch **firmware**. It enables the native on-screen keyboard and other Switch firmware features (system fonts, keyboard layouts). The installer finds firmware installed by common emulators; your dump stays unchanged.

The downloads contain no game files, keys or firmware.

<details>
<summary>Technical details</summary>

- **Game builds** download the current `main` source when a build starts; the installer itself is versioned separately.
- **Updates:** the installer checks for newer releases and verifies an Ed25519-signed manifest before replacing itself (macOS app, Linux AppImage, Windows `.exe`).
- **Windows:** one executable. Runtime, build tools and helpers are inside it and unpack to `%APPDATA%` on first start. Qt, FFmpeg and SDL3 are fetched from their publishers on first use.
- **Linux:** where FUSE is unavailable, run the AppImage with `--appimage-extract-and-run`.
- **macOS "damaged" message:** download the file again and compare it with `SHA256SUMS` (`shasum -a 256 <file>`). Only if the checksum matches, you can remove the download flag with `xattr -dr com.apple.quarantine "Strahlender Installer.app"` and open the app again.
- **Checksums:** `SHA256SUMS`. Every download is built on its native architecture in GitHub Actions.

</details>
