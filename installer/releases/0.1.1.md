# Strahlender Installer 0.1.1

| System | Download |
| --- | --- |
| macOS (Apple Silicon and Intel) | `installer-macos-universal.zip` |
| Linux x86_64 | `Strahlender-Installer-x86_64.AppImage` |
| Linux ARM64 | `Strahlender-Installer-aarch64.AppImage` |
| Windows x86_64 | `Strahlender-Installer-x86_64.exe` |

- Windows: a single `.exe` instead of a ZIP with a folder. The build tools are included.
- Windows: the installer can update itself.
- macOS: the game build runs through to the finished app again (linker and packaging errors fixed).

You need your own `prod.keys`, the base game and optionally the update. The downloads contain no game files. Checksums are in `SHA256SUMS`.
