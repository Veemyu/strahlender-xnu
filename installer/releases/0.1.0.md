# Strahlender Installer 0.1.0

First release.

| System | Download |
| --- | --- |
| macOS (Apple Silicon and Intel) | `installer-macos-universal.zip` |
| Linux x86_64 | `Strahlender-Installer-x86_64.AppImage` |
| Linux ARM64 | `Strahlender-Installer-aarch64.AppImage` |
| Windows x86_64 | `installer-windows-x86_64.zip` (replaced by a single `.exe` in 0.1.1) |

- Guided game build from your own `prod.keys`, base game, optional update and mods.
- macOS and Linux builds confirmed; Mac-hosted iPhone/iPad builds are connected.
- Pure RomFS mods need no rebuild; ExeFS/IPS mods build on Mac and iPhone/iPad.

You need your own `prod.keys`, the base game and optionally the update. The downloads contain no game files. Checksums are in `SHA256SUMS`.
