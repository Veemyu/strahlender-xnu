# From your game files to your own app

The first **Strahlender Installer** preview is here: a small, native Rust/Iced
app that guides you through building Brilliant Diamond / Shining Pearl for your
devices. Drag in your files, choose a target, and follow the build as it happens.

## Pick your download

| Your computer | Installer |
| --- | --- |
| Mac · Apple Silicon | `installer-macos-aarch64.zip` |
| Mac · Intel | `installer-macos-x86_64.zip` |
| Linux · x86_64 | `installer-linux-x86_64.AppImage` |
| Linux · ARM64 | `installer-linux-aarch64.AppImage` |

macOS: unzip and open **Strahlender Installer.app**. These preview builds are
ad-hoc signed and not notarized; macOS may require you to allow the app in
**System Settings → Privacy & Security**.

Linux: mark the AppImage as executable and open it. A portable `.tar.gz` is also
available if AppImage mounting is unavailable on your system.

## A small app, a visible build

- Step-by-step views for your keys, base game, optional update and mods.
- Automatic `prod.keys` discovery in standard emulator folders, with manual
  selection and remembered file choices when you need them.
- Native Mac and Linux game builds; Mac-hosted iPhone/iPad builds are also
  connected, with Xcode/device setup required.
- Separate extraction, code generation, compilation and installation phases,
  real file counters, and an expandable, copyable build log.
- Dark mode by default, optional light mode, and bundled fonts and icons.
  The installer includes its own Python runtime: no Rust or Python installation
  is needed to open it.

Complete GUI game builds have been confirmed on macOS and Nobara Linux. Each
download is built on its native architecture and checked in GitHub Actions.

## Bring your mods, too

Select the whole downloaded mod folder: the installer finds its RomFS and ExeFS
content. **Pure RomFS mods need no rebuild** and can also be copied through your
file manager. Supported ExeFS/IPS/IPS32 mods use an isolated code build; a
separate mod app can keep its own identity, icon and save.

Mod integration has been exercised with **Luminescent Platinum**, including its
own artwork. Full Lumi playthrough validation remains in progress. Code-mod
builds currently target Mac and iPhone/iPad from a Mac; Linux ExeFS mod builds
are not available yet.

## What this preview needs

Bring your own **prod.keys**, base game and optional update. These downloads
contain no game files or keys. Building the game still requires platform build
tools; the setup check explains missing dependencies and provides guided setup.
First-use dependency installation on fresh systems is still being validated.

Game builds download the current `main` source when you start a build. The
installer itself is versioned separately. Windows installer downloads and the
Android backend remain future work. Automatic installer replacement is not
enabled in these initial downloads; newer installers are available through
GitHub Releases.

`SHA256SUMS` contains the download checksums; `installer-build.json` identifies
the exact installer source revision.
